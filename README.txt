NSTU MEET — обновлённый проект
==============================

В проект добавлены:
- современный тёмный дизайн с фиолетово-розовыми градиентами и анимациями;
- регистрация с выбором страны и вуза, включая НГТУ, СГУПС, СибГУТИ, НГУМУ, НГУЭУ и НГУ;
- отметка, что вуз указан честно (это само-декларация, не проверка обучения);
- рекомендации сначала по стране и вузу; бесплатные аккаунты видят свой вуз, Premium — поддерживаемые вузы;
- загрузка до 6 фото в анкету;
- отдельные страницы «Мои лайки», «Кто меня лайкнул» (Premium), «Чаты»;
- фото и видео в личных чатах и автоматическая подгрузка новых сообщений каждые 2,5 секунды;
- создание Premium-групп, вступление и сообщения внутри группы;
- студенческий маркетплейс с объявлениями, ценой и фото, фильтром по вузу;
- обновлённая адаптивная верстка для телефона и компьютера.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
------------------
1. Платёжная система не активирована автоматически. Кнопка оплаты Premium заработает только после настройки YooKassa в Render и проверки полного платёжного сценария. Не вставляй секретные ключи в код или GitHub.
2. Сейчас SQLite и загруженные файлы хранятся в локальной файловой системе сервиса. На бесплатном Render она может очищаться при новом развёртывании/перезапуске. Для реального использования подключи постоянную PostgreSQL и отдельное постоянное хранилище изображений/видео. Не приглашай широкую аудиторию и не храни важные данные до этого.
3. Выбор вуза при регистрации — честное само-указание, не подтверждение студенческого статуса.
4. Это расширенная рабочая заготовка, но перед публичным запуском нужны CSRF-защита, ограничения частоты запросов, модерация жалоб, политика конфиденциальности, правила сервиса, безопасное удаление данных и тестирование на реальных устройствах.
5. Сервис рассчитан на пользователей 18+.

ЛОКАЛЬНЫЙ ЗАПУСК WINDOWS
------------------------
1. Установи Python 3.11+.
2. Распакуй архив. Открой именно папку, где лежат app.py, requirements.txt, render.yaml, static и templates.
3. В адресной строке папки Проводника введи cmd и нажми Enter.
4. Выполни:
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   py app.py
5. Открой http://127.0.0.1:5000.

ОБНОВЛЕНИЕ GITHUB ЧЕРЕЗ БРАУЗЕР
-------------------------------
1. Скачай и распакуй ZIP.
2. Открой папку nstu_meet внутри архива. Именно её содержимое нужно загрузить в корень репозитория — не создавай дополнительную вложенную папку nstu_meet.
3. Открой свой репозиторий GitHub и нажми Add file → Upload files.
4. Перетащи файлы и папки ИЗНУТРИ nstu_meet: app.py, requirements.txt, render.yaml, README.txt, .env.example, папки static и templates, а также .gitignore.
5. Когда GitHub предложит заменить существующие файлы, подтверди замену. Новые файлы добавь. Не удаляй вручную репозиторий и не меняй адрес сайта.
6. Нажми Commit changes.
7. В Render открой сервис nstu-meet → Events/Logs и дождись завершения нового deploy со статусом Live. Если автоматическое развёртывание включено, оно начнётся само после коммита.
8. Открой сайт по прежнему адресу и проверь регистрацию, профиль, фото, лайки, чат, группы и объявления.

НЕ ЗАГРУЖАЙ В GITHUB
--------------------
- .env с настоящими ключами;
- nstu_dating.db или другие файлы базы данных;
- папку uploads с пользовательскими фото/видео;
- пароли, токены, ключи платёжной системы.
