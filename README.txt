NSTU MEET — адаптивный сайт знакомств для сообщества НГТУ
==========================================================

Обновлено:
- адаптивная верстка для компьютеров, планшетов и телефонов;
- дополнительные плавные анимации;
- PWA-манифест: после публикации по HTTPS сайт можно добавить на главный экран телефона;
- конфигурация для публикации на Render;
- приложение принимает PORT от хостинга и запускается через Gunicorn;
- локальный запуск Windows сохранён.

ВАЖНО: «РАБОТАЕТ ВСЕГДА И ВЕЗДЕ»
--------------------------------
Код не может обеспечить доступ 24/7, если сайт работает только на твоём ноутбуке.
Чтобы сайт открывался у других людей и с телефона, его нужно опубликовать на хостинге.
Публикацию нужно выполнить в твоём аккаунте. Бесплатные тарифы могут засыпать и не гарантируют
абсолютный аптайм. SQLite-файл может потеряться при пересоздании сервиса — для настоящего запуска
подключи постоянное хранилище или управляемую PostgreSQL.

ЛОКАЛЬНЫЙ ЗАПУСК WINDOWS 11
--------------------------
1. Установи Python 3.11+.
2. Распакуй архив, открой папку, введи cmd в адресную строку Проводника.
3. Выполни:
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   py app.py
4. Открой http://127.0.0.1:5000. Пока тестируешь, окно командной строки не закрывай.

ПУБЛИКАЦИЯ НА RENDER (ОБЩАЯ СХЕМА)
----------------------------------
1. Создай репозиторий GitHub и загрузи содержимое папки проекта. Не загружай .env, базу данных и ключи.
2. На Render выбери New > Web Service и подключи репозиторий.
3. Build Command: pip install -r requirements.txt
4. Start Command: gunicorn app:app
5. Добавь SECRET_KEY как секретную переменную окружения; COOKIE_SECURE=1 при HTTPS.
6. Deploy. После публикации получишь публичную HTTPS-ссылку — её можно открывать на телефоне.
Файл render.yaml содержит базовую конфигурацию, но конкретные шаги в панели могут меняться.

ПЕРЕД РЕАЛЬНЫМ ЗАПУСКОМ
-----------------------
Нужно настроить постоянную БД, CSRF-защиту, ограничение частоты запросов, модерацию жалоб,
политику конфиденциальности, условия использования и безопасное удаление персональных данных.
YooKassa требует своих ключей и проверки платёжного сценария.
Факультет и курс вводятся самостоятельно и пока не подтверждают обучение в НГТУ.
Сервис рассчитан только на пользователей 18+.
